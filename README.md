# 🏥 Hospital Management System (Django REST Framework)

A fully functional **Hospital Management System API** built with python & Django and Django REST Framework.  
The project manages department, patients, doctors,days, appointments, payment,accounts and authentication with secure role-based permissions.

---

## 🚀 Features

- 🔐 User Authentication (Login / Register / JWT)
- 👨‍⚕️ Doctor Management
- 🧑‍⚕️ Patient Management
- 📅 Appointment Scheduling System
- 📊 Admin Dashboard APIs
- 🔒 Role-Based Permissions (Admin / Doctor / User)
  
## 🛠 Tech Stack

- Python 3
- Django
- Django REST Framework
- Simple JWT Authentication
- mysql
- Postman (for API testing)
